## 2025-02-15 - Replace Insecure File Open and Command Execution Methods in Perl
**Vulnerability:** The Perl codebase extensively used the insecure 2-argument `open()` function (e.g., `open(FH, ">$file")`) which is vulnerable to injection if `$file` contains magic characters like `|` or `>`. It also executed external commands using backticks without safely passing arguments (e.g., `` `tasklist ...` `` and `` `ps -o ...` ``), leading to potential command injection.
**Learning:** Legacy Perl scripts often utilize short-hand 2-argument opens and backticks for convenience, but these introduce significant security risks when combined with dynamic inputs or paths. These practices can compromise the host executing the generation scripts.
**Prevention:** Always use the 3-argument version of `open()` (e.g., `open(FH, '>', $file)` or `open(FH, '-|', @command)` for safe pipe execution). For executing external commands, use array-based list execution with `system` or `open('-|', @args)` rather than backticks or scalar `system()` to ensure arguments are not passed to a shell and interpreted.
