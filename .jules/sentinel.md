## 2024-05-24 - RCE in Console Action Execution
**Vulnerability:** The interactive console in `Console.pm` was taking arbitrary user input for actions (like `action simulate(...)`) and constructing a Perl string `$model->$action($options)`, which was then executed using `eval`. This allowed an attacker to break out of the method call syntax and execute arbitrary system commands (e.g., `action simulate(...); system('id')`).
**Learning:** Even when the core system uses safe evaluation (`Safe->reval` or explicit parsed arguments via `BNGModel::_invoke_model_action`), wrapper interfaces or consoles might still insecurely re-implement parsing using unsafe string `eval`. This codebase pattern showed that user input was not sanitized before string evaluation.
**Prevention:** Never use string `eval` on user-supplied input to perform dynamic method invocation. Always route dynamic execution through established, safe parsing pipelines that separate code from data (like `BNGModel::_invoke_model_action` which uses `Safe->reval` with restricted opcode permissions) and invoke methods natively `eval { $obj->$method(@args) }`.
