## 2024-04-24 - Safely Optimize BioNetGen Python Parser Bond Removals
**Learning:** In the BioNetGen Python parser classes (e.g., `parsers/utils/smallStructures.py`), component bonds are stored as strings and may contain non-integer characters like `'+'` representing wildcards. Attempting to optimize `removeMolecule` logic by casting component bonds to integers `int(b)` to check against a set will crash with `ValueError: invalid literal for int() with base 10: '+'`. The codebase also relies on identity references for component lists, so reassigning lists directly using comprehensions must be done with slice assignment (`[:] = ...`) to preserve references.
**Action:** When optimizing list removals or membership tests for BioNetGen bonds, pre-cast the target bond numbers to a set of strings, and use `[:] = [b for b in component.bonds if b not in bond_strs]` to safely mutate the list in-place and avoid runtime parsing errors.
